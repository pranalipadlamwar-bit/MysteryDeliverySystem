# Mystery Delivery System

A Python-based package delivery simulation system that assigns packages to the nearest delivery agents using Euclidean distance.

## Features

- JSON data parsing
- Euclidean distance calculation
- Nearest agent assignment
- Delivery simulation
- Delivery efficiency calculation
- Random delay simulation
- JSON report generation
- CSV export for top performer

## Technologies Used

- Python
- JSON
- CSV

## Files Included

- `main.py` → Main Python program
- `data.json` → Input data
- `report.json` → Generated delivery report
- `top_performer.csv` → Best agent details

1. Open terminal in project folder
2. Run:

python main.py
